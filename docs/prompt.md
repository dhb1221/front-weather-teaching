## 【完整提示词】

```text
你是一位同时精通「高中地理教学 + Web 前端 + 3D 可视化 + 联网数据」的专家。请独立完成一个交互式教学网页《锋与天气》（人教版高中地理必修第一册「常见天气系统」）。它要能直接双击离线打开、也能部署到 GitHub Pages；既要有教科书级的准确性，也要有让人一眼看懂的表现力，可直接用于课堂投屏和视频录制。

━━ 零、设计总则 ━━
1. 「同一份数据驱动所有视图」：三维场景、剖面图、天气图、曲线、实况页必须共用同一个状态（锋面类型 + 时间轴 t），任何视图都不能自己编数据。
2. 「先讲清原理，再给结论」：每个天气结论旁边都要能追问「为什么」，并给出因果链（气团性质 → 密度差 → 锋面坡度 → 抬升方式 → 云系 → 降水性质 → 过境前后天气）。
3. 「宁可少而准，不可多而错」：所有数据、日期、图示必须真实可查；拿不准就标注「示意」，不许编造实况数值。
4. 「课堂上 3 秒能看懂」：一屏只讲一件事，信息层级、颜色语义、图例固定。

━━ 一、核心教学逻辑（最重要，不许偏离） ━━
1. 顶部三个按钮：冷锋、暖锋、准静止锋。点击任一按钮后，动画立即重置并从「过境前」开始播放，画面、数据、文案全部切换为该锋面，不能残留上一种锋面的元素。
2. 每种锋完整呈现「过境前 → 过境时 → 过境后」三阶段，用可拖动时间轴控制，支持播放/暂停、0.5×/1×/2× 倍速、单步微调。
3. 场中央固定「观测站」（小房子 + 风向旗 + 地名），锋面随时间从一侧扫过观测站。阶段与锋面相对观测站的位置严格对应：未到=过境前，正在扫过=过境时，已远离=过境后。切换锋面时观测站位置不变，只有锋面结构与运动方向变化。
4. 天气描述必须与教材一致（逐字核对）：
   冷锋：过境前受暖气团控制，气温高、气压低、天气晴朗；过境时出现大风、降温、阴天、雨雪，降水为阵性、强度大历时长——不，是强度大、历时短，降水集中在锋线附近及锋后（冷气团一侧）；过境后受冷气团控制，气温下降、气压升高、天气转晴。
   暖锋：过境前受冷气团控制，气温低、气压高、天气晴朗；过境时出现连续性降水，强度小、历时长，降水集中在锋前（冷气团一侧）；过境后受暖气团控制，气温升高、气压降低、天气转晴。
   准静止锋：冷暖气团势力相当，锋面移动缓慢或来回摆动，雨带长时间停留，出现持续时间很长的连续性降水（阴雨连绵）；江淮准静止锋形成梅雨（6 月中旬—7 月上旬，约 20 天），昆明准静止锋使贵阳冬半年阴雨、昆明晴暖。
5. 实时读数：画面上持续显示气温、气压、天气现象、风向风力，且数字随动画连续变化（由函数生成，不是写死的字）。
   参考取值：冷锋 25℃→17℃、1002→1014 hPa；暖锋 6℃→15℃、1020→1008 hPa；准静止锋 12℃ 左右、1013→1011 hPa，变化很小。
6. 每个阶段配「为什么会这样？」折叠解析（1~3 句），且与知识库内容一致。

━━ 二、必须呈现的视觉要素 ━━
1. 冷气团与暖气团：蓝色系 / 橙色系的半透明团块，内部有缓慢流动的粒子或流线；冷气团要能看出「楔形」「密度大、贴地」的形态，暖气团要能看出「被抬升、沿锋面爬坡」。
2. 锋面：倾斜的界面（不是一条线）。坡度按类型区分：冷锋陡、暖锋缓、准静止锋最缓；标注坡度的数量级（冷锋约 1/50～1/100，暖锋约 1/100～1/300）。锋面与地面的交线是锋线，发光高亮，并标出「锋面」「锋线」。
3. 锋面符号：冷锋为三角形（尖端指向移动方向），暖锋为半圆（凸出方向指向移动方向），准静止锋为三角形与半圆交替、分别画在锋线两侧。符号必须画对方向，并能在地面、天气图、图例三处复用。
4. 气流箭头：冷锋要看到冷气团楔入暖气团下方、暖空气被迫抬升；暖锋要看到暖空气沿缓坡缓慢爬升；准静止锋要看到暖湿空气持续沿锋面爬升。箭头要有粗细/颜色/动态流动区分，可开关。
5. 云：冷锋高耸积雨云（云体高、范围窄、顶部可到画面高处）；暖锋多层层状云（雨层云/高层云/卷层云，薄而广）；准静止锋层状云范围更宽、更持久。云会随时间生成、移动、消散，并随锋面位置平移。
6. 降水：位置必须正确——冷锋在锋后（冷气团一侧）及锋线附近；暖锋在锋前（冷气团一侧），雨带宽；准静止锋在锋面附近，雨带最宽、持续时间最长。雨滴用短斜线/粒子，落地有雨幕/涟漪呼应；气温低于 0℃ 显示雪花；降水强度要与雨滴密度、云厚、曲线数值一致。
7. 标注：冷气团、暖气团、锋面、锋线、云雨区、观测站、移动方向、坡度；标注不遮挡主体、不互相重叠，可开关。
8. 图例：颜色与符号含义一目了然，固定位置、不随视角乱跑。
9. 地面与空间：深色地面 + 若有若无的网格，体现「空间感」；锋线沿地面横向延伸，能看出这是「一个面」而不是「一条线」。

━━ 三、多角度观看（作品亮点，必须做足） ━━
1. 三维主视图支持鼠标拖拽 360° 环绕、滚轮/双指缩放；手机单指拖拽、双指缩放，不与页面滚动冲突。
2. 提供 5 个预设视角按钮，切换要平滑过渡（缓动，不瞬移）：
   ①斜视（默认，地面 + 锋面 + 云都能看到）②正剖面（视线平行地面、垂直于锋线，等同教科书剖面）③俯视（看锋线与降水带范围）④从冷气团一侧看（看冷空气推进、云从头顶压来）⑤从暖气团一侧看（看暖空气爬升、云系铺展）。
3. 额外 5 个联动视图（同一时间轴，切换不打断动画，除非切换锋面类型）：
   ①剖面图：教科书式 2D 剖面，冷/暖气团、锋面坡度、积雨云或层状云、降水、观测站与风向旗、锋面符号，顶部「过境前/时/后」信息条与读数；
   ②天气图：俯视天气图，含锋面气旋（北半球左侧冷锋、右侧暖锋、低压中心、逆时针辐合风向、冷锋后与暖锋前降水区），以及我国锋面雨带推移（4—5 月华南、6 月江淮梅雨、7—8 月华北东北、9 月南退，可切换月份看位置变化）；
   ③要素曲线：气温（左轴）、气压（右轴）、降水强度（柱）随时间变化，播放头跟随动画，过境时的骤变/缓变一眼可见，并标注「过境时」区间；
   ④实况天气（联网，见第六节）：真实城市当天天气 + 锋面类型判读 + 与教材典型值对照；
   ⑤知识库：完整原理讲解、对比表、易错点、例题、术语表，带目录跳转与搜索。
4. 所有视图共享时间轴与锋面类型；在任一视图操作时间轴/锋面，其他视图同步。

━━ 四、知识内容（必须全部覆盖，讲原理而不是堆结论） ━━
1. 气团与锋：气团概念与形成条件、冷气团/暖气团的性质（温度、密度、湿度）、锋/锋面/锋线/锋区、锋面坡度、锋的形成与移动。
2. 冷锋：结构、符号、三阶段天气、快行冷锋与慢行冷锋的区别、降水为什么在锋后、实例（北方夏季暴雨、冬季寒潮、春季沙尘暴、一场秋雨一场寒）与防御措施。
3. 暖锋：结构、符号、三阶段天气、降水为什么在锋前、云系演变（卷云→卷层云→高层云→雨层云）、实例（一场春雨一场暖）。
4. 准静止锋：形成条件、江淮准静止锋与梅雨、昆明准静止锋（贵阳阴雨/昆明晴暖的原因）、华南准静止锋、持续阴雨的影响。
5. 三种锋对比大表：坡度、云系、降水位置、降水性质、移动方向、过境后气温、过境后气压、典型实例、符号、记忆口诀——≥9 行 × 6 列，可扫读。
6. 锋面气旋：北半球「左冷右暖」的判读、冷暖锋与气旋中心的位置关系、降水区（冷锋后、暖锋前）、过境天气顺序、判读步骤（定中心→定半球→定前后→定降水）。
7. 我国锋面雨带推移：与夏季风、副热带高压的关系；4—5 月华南、6 月江淮梅雨、7—8 月华北东北、9 月南退；雨带异常与旱涝（南涝北旱 / 北涝南旱）。
8. 判读方法：等压线图判读（锋面在哪里、哪个是冷锋）、锋面符号判读、气温气压曲线判读、卫星云图判读、常见设问与答题模板（「描述天气变化」怎么写、「判断锋面类型并说明理由」怎么答）。
9. 易错点 ≥10 条：暖锋降水在锋前、冷锋过境后气压升高、准静止锋并非「不动」、锋面符号方向、冷锋不一定都下暴雨、昆明准静止锋昆明不在暖气团一侧而是……（按教材表述写准）等。
10. 经典例题 ≥4 题：题干 + 选项 + 答案 + 解析（解析要写思维过程，不只给结论）。
11. 生活中的锋：寒潮、沙尘暴、梅雨、回南天、一场秋雨一场寒 / 一场春雨一场暖、天气预报里的锋面符号。
12. 术语速查表 ≥12 条：气团、锋面、锋线、锋区、冷锋、暖锋、准静止锋、快行/慢行冷锋、锋面气旋、雨带、副热带高压、连续性降水、阵性降水等。
呈现要求：标题分级 + 重点加粗 + 原理提示框（浅蓝）/ 易错框（橙色）/ 必背结论框（绿色）；句子短、可扫读；每个结论回答「是什么—为什么—怎么考」。

━━ 五、联网实况天气（新增重点，必须真的联网） ━━
1. 支持查询任意城市「当天实时天气」：
   - 城市搜索（中文名可搜，如「北京」「贵阳」「乌鲁木齐」）+ 常用城市快选（北京/上海/广州/哈尔滨/武汉/昆明/贵阳/乌鲁木齐）+ 浏览器定位（授权失败要有兜底，不要卡死）。
   - 显示：当前气温、体感温度、气压（hPa）、海拔（m）、相对湿度、风向风速、阵风、云量、能见度、天气现象、降水量（近 1h / 3h / 24h）、露点、紫外线；并显示数据更新时间与时区。
2. 用真实数据做「锋面判读」，给出结论 + 判据 + 解释，不能只给结论：
   - 冷锋过境：24h 内降温 ≥4℃、气压升高 ≥3 hPa、风向由偏南转偏北、有阵性降水；
   - 暖锋过境：24h 内升温 ≥3℃、气压降低 ≥3 hPa、云量高、有连续性降水；
   - 准静止锋：24~48h 内温压变化小（|ΔT|<2.5℃、|ΔP|<2 hPa）、降水持续时间长；
   - 无明显锋面过境：以上均不满足，说明本地受单一气团控制。
   判读卡要列出：结论、置信度（高/中/低）、逐条判据数值、一句话解释、以及「接下来 24 小时可能怎样变化」。
3. 实况曲线：过去 12~24h 到未来 24h 的气温、气压、降水三条线（或双轴 + 柱），标出「现在」的位置；可切换城市。
4. 与教材对照：把实况数值与三种锋的典型值并排展示，说明「真实天气为什么往往不像教材那么典型」。
5. 一键重现：点「用这次实况演示」→ 自动选中对应的锋面类型、把时间轴跳到「过境时」，在三维场景里重现这次天气过程（数据来源标注为实况）。
6. 数据要求：优先免密钥、允许跨域的公共天气接口（如 wttr.in、MET Norway、Open-Meteo 等）；多源降级（首个失败自动换下一个）；明确显示数据来源与更新时间；请求超时 8 秒、失败给明确文案和「重试」，绝不伪造数据；离线时该页显示「无网络，仅展示教学示例」并可用手动输入（温度/气压/降水）做判读。
7. 隐私与合规：定位仅在用户点击授权后使用，不存储、不上传；页面用 https 部署。

━━ 六、技术实现要求 ━━
1. 三维用 three.js，二维用 Canvas/SVG；不靠图片拼贴；three.js 与所有脚本内联进单文件（可先 CDN 开发，最终必须能断网打开）。
2. 单文件 HTML 优先（双击即开），同时保留可维护的源码结构（src/ 分模块、构建脚本、README）。
3. 性能：桌面与中端手机 55~60fps；粒子数自适应；页面无控制台报错；切换到 2D 视图或页面不可见时暂停 3D 渲染。
4. 手机竖屏优先：单列布局、按钮不挤、字号可读、禁止横向滚动、触控不与滚动冲突；桌面宽屏用左右分栏。
5. 视觉：深色科技感（#05070f 系底）+ 冷蓝 #4ea1ff / 暖橙 #ff8a3d / 降水蓝 #8fc8ff / 准静止锋紫 #b98cff；玻璃拟态面板；中文字体 PingFang SC / Microsoft YaHei；投影仪远距离可读。
6. 交互：播放/暂停、倍速、时间轴拖动、切换锋面重置、显示开关（坡度/气流/云/降水/标注/网格）、天气图子模式、雨带月份、题库（≥30 题，随机抽题，即时判分 + 解析）、实况城市切换、URL 参数保存情景（type/t/view/city/lat/lon/play，便于课前存链接）。
7. 键盘：空格播放/暂停、←/→ 步进、1/2/3 切换锋面、0 重置。
8. 无障碍：键盘可操作、颜色之外再用形状/文字区分冷暖、对比度达标、支持字号放大。
```

## 【追加增强指令】（想要更高要求时，接在完整提示词后面）

```text
在上述基础上再追加：
1. 「追问式教学」：每个阶段旁放一个「为什么会这样？」按钮，点开给 1~2 句因果链（气团性质→密度差→锋面坡度→抬升→云→降水→过境后天气），并且与知识库同一套说法。
2. 「判读训练」：给 5 幅等压线/锋面示意图，学生点选「冷锋还是暖锋」「降水在锋前还是锋后」「过境后气温气压怎么变」，即时反馈、计分、可重做；错题自动进错题本。
3. 「真实案例库」：寒潮、沙尘暴、江淮梅雨各一个由本页数据驱动的演示，配真实日期与地区（标注来源），讲清天气过程与影响。
4. 「教师模式」：一键隐藏所有答案/解析，便于课堂提问；再一键进入全屏投屏（大字号、隐藏面板）。
```
