# 锋与天气 · 高中地理交互教具

一个**离线可用、单文件分发**的「锋与天气」交互实验室：冷锋 / 暖锋 / 准静止锋三种天气系统，用可旋转的立体模型、剖面图、真实底图天气图、要素曲线、知识库与联网实况 6 个视角，把「锋是什么、怎么移动、过境前/时/后天气怎么变」一次讲透。

> 面向高中地理（人教版必修一「常见天气系统」）课堂演示与学生自主复习。

---

## ✨ 功能一览

| 视角 | 内容 | 训练目标 |
| --- | --- | --- |
| ① 立体空间 | three.js 三维场景：冷/暖气团、倾斜锋面、锋线、云雨区、观测站与 5 个预设机位（斜视/正剖面/俯视/冷气团侧/暖气团侧），可拖拽旋转、双指缩放 | 建立「锋面是倾斜界面」「暖气团被抬升」的空间概念 |
| ② 剖面图解 | Canvas 剖面：气团、锋面坡度、积雨云/层状云、雨雪与涟漪、观测站风向旗、地面锋面符号、三阶段信息条 | 过境前/时/后的天气与风向变化 |
| ③ 天气图 | 锋面气旋（真实海岸线）、我国雨带推移（真实中国底图，4–9 月可调，含南海诸岛插图）、锋面符号判读 | 读图判读、雨带与副高 |
| ④ 要素曲线 | 双轴气温/气压曲线 + 降水柱 + 三阶段分区 + 播放头，数值随动画实时更新 | 定量理解要素变化 |
| ⑤ 知识库 | 12 节系统知识 + 术语速查表 + 易错点 + 例题，支持搜索 | 系统复习、查漏补缺 |
| ⑥ 实况天气 | 联网获取任意城市当前天气，按冷暖锋判据自动判读，一键回到课堂演示；可手动输入兜底 | 把课本判据用到真实天气 |

## 🚀 使用

**在线**：GitHub Pages 打开 `docs/index.html`。

**离线**：下载仓库里的 `docs/index.html`（约 1.2 MB，单文件），双击用浏览器打开即可——不联网也能用全部 5 个教学视角（只有「实况天气」需要网络）。

**手机**：同一个文件在手机浏览器打开，窄屏自动切换单列布局；三维不可用的设备会自动降级到剖面图解并提示。

## ⌨️ 快捷键

- `空格` 播放/暂停 · `←` `→` 微调时间（±0.02）· `R` 重置
- `1` / `2` / `3` 切换冷锋 / 暖锋 / 准静止锋 · `K` 打开练习 · `Esc` 关闭弹层

## 🧠 教学逻辑（与教材对齐）

1. 冷锋：冷气团主动向暖气团移动 → 锋面坡度陡 → 暖气团被迫抬升 → 积雨云、阵性降水 → 过境时大风、降温、雨雪，过境后气温下降、气压升高、天气转晴。
2. 暖锋：暖气团主动爬升 → 锋面坡度缓 → 层状云、连续性降水 → 过境后气温上升、气压下降、天气转晴。
3. 准静止锋：冷暖气团势均力敌，锋面原地摆动 → 长时间阴雨（江淮梅雨、昆明准静止锋）。

所有读数的气温/气压/降水/云量/风向都来自同一份共享数据 `src/front-data.js`，图表、剖面、三维、知识库口径完全一致。

## 🗺️ 地图与数据严谨性

- **中国地图**：省级以上行政边界来自 DataV.GeoAtlas 公开数据（自然资源部标准地图服务体系下的公开数据），含**台湾省、香港、澳门**，并单独绘制**南海诸岛九段线**；采用兰勃特等角圆锥投影（标准纬线 25°N/47°N，中央经线 105°E）。
- **世界地图**：Natural Earth 1:110m（公有领域），仅作示意性底图。
- **实况天气**：Open-Meteo 地理编码（城市检索）+ wttr.in（主源）+ MET Norway（备源），超时自动降级；**不伪造数据**，取不到就提示手动输入。教材使用「24 小时气温/气压变化」，但免费公开源通常没有昨日同时刻实测值，所以页面用**今日已过时段**的变化近似，并在结论里注明真实时间跨度，不冒充 24 小时。

## 🛠️ 开发与构建

```bash
# 开发：本地起静态服务即可
python3 -m http.server 8123

# 自检（零依赖，全部通过才正常）
node tools/selftest.mjs

# 构建单文件离线版 → docs/index.html
node build.mjs

# 重新生成地图数据（一般不需要，raw 数据已入库）
node tools/build-geo.mjs
```
