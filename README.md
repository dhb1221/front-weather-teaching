# 锋与天气 · 高中地理交互教具

一个**离线可用、单文件分发**的「锋与天气」交互实验室：冷锋 / 暖锋 / 准静止锋三种天气系统，用可旋转的立体模型、剖面图、要素曲线、知识库、联网实况与 geo-three 三维地球共 7 个视角，把「锋是什么、怎么移动、过境前/时/后天气怎么变」一次讲透。

> 面向高中地理（人教版必修一「常见天气系统」）课堂演示与学生自主复习。

## 🚀 使用

**在线**：GitHub Pages 打开 `docs/index.html`。

**离线**：下载仓库里的 `docs/index.html`（约 1.4 MB，单文件），双击用浏览器打开即可——不联网也能用 6 个教学视角（①、②、③、④、⑥，以及 ⑦ 三维地球的离线底图、气压带与标注）；只有 ⑤「实况天气」和 ⑦ 的「等压线／实时」需要网络，断网时页面会明确提示。

**手机**：同一个文件在手机浏览器打开，窄屏自动切换单列布局；三维不可用的设备会自动降级到剖面图解并提示。

## 🧠 教学逻辑（与教材对齐）

1. 冷锋：冷气团主动向暖气团移动 → 锋面坡度陡 → 暖气团被迫抬升 → 积雨云、阵性降水 → 过境时大风、降温、雨雪，过境后气温下降、气压升高、天气转晴。
2. 暖锋：暖气团主动爬升 → 锋面坡度缓 → 层状云、连续性降水 → 过境后气温上升、气压下降、天气转晴。
3. 准静止锋：冷暖气团势均力敌，锋面原地摆动 → 长时间阴雨（江淮梅雨、昆明准静止锋）。

所有读数的气温/气压/降水/云量/风向都来自同一份共享数据 `src/front-data.js`，图表、剖面、三维、知识库口径完全一致。

## 🗺️ 地图与数据严谨性

- **中国地图**：省级以上行政边界来自 DataV.GeoAtlas 公开数据（自然资源部标准地图服务体系下的公开数据），含**台湾省、香港、澳门**，并单独绘制**南海诸岛九段线**；采用兰勃特等角圆锥投影（标准纬线 25°N/47°N，中央经线 105°E）。
- **世界地图**：Natural Earth 1:110m（公有领域），仅作示意性底图。
- **实况天气**：内置 `geo-cities.js`（由 DataV 行政区划生成，375 个地级市/直辖市/港澳台城市，含省份）优先本地检索，未命中再走 Open-Meteo 地理编码；天气数据用 Open-Meteo（主源）+ MET Norway（备源）**双源竞速**、超时自动降级，详见下节「数据源与准确性」。**不伪造数据**，取不到就提示手动输入。
- **三维地球底图**：不是在线瓦片服务，而是运行时用 canvas 把 Natural Earth 1:110m 世界边界与中国省界画成 256px 瓦片（z0–z3），再交给 geo-three 的球面地图层做四叉树 LOD，因此离线、无 Key、无第三方请求。

## 📡 数据源与准确性

- **双源竞速**：⑤「实况天气」同时请求 Open-Meteo（`api.open-meteo.com`）与 MET Norway（`api.met.no`）两个免密钥、开放 CORS 的数值预报接口，**先成功且解析通过者胜**，页面标注本次实际来源；两个都失败才报错，绝不编造数值。⑦ 的全球 8 城实时天气用 Open-Meteo 多坐标批量请求，批量不可用时自动降级为 8 个单点请求。
- **数值模式 ≠ 气象站实测**：两家返回的都是**数值模式**（模式网格插值/预报）数据，页面在来源、告警与判读结论里原样注明。教材中的「24 小时气温/气压变化」在免费公开源上拿不到昨日同刻实测，因此用**今日 0:00（或最早可用点）→ 当前**的模式值近似，并写明真实小时数，不冒充 24 小时；MET Norway 备源没有过去时段，只能用「未来约 9 小时预报变化」代替并明确标注。
- **自动刷新与数据时间**：⑤ 视图打开后每 **5 分钟**（`window.LIVE.REFRESH_MS = 300000`）自动重新取数，也可点「刷新」立即更新；⑦ 的 8 城实时标记每 **8 分钟**自动刷新（与数据层 8 分钟内存缓存对齐，避免重复请求）。结果区展示**数据时刻（模式时刻）与来源**，⑦ 地球信息条展示「更新于 HH:MM（Open-Meteo）」。
- **全球气压场是真实数据，锋面不再推导**：⑦ 的等压线来自 Open-Meteo 的**全球海平面气压网格**（15° 网格，11×24=264 点，取 pressure_msl），用 marching squares 生成 4 hPa 间隔等压线后贴到球面；数据每 **30 分钟**刷新一次（该产品本身按小时更新），页面信息条展示「气压场：实时（HH:MM，Open-Meteo 模式场）」。锋线**不做自动推导**：国家气象部门发布的锋线图只有图片、没有稳定可机读的全球几何数据（NOAA 的锋面 GeoJSON 仅覆盖北美预报图），因此本页只呈现有据可查的气压场，不画推测的锋面。
- **取数额度与 429**：Open-Meteo 免费额度按「点数」计——实测 **600 点/分钟、5000 点/小时、10000 点/天**。一次全球气压网格 264 点、8 城 8 点，正常使用（每次打开取一次、30 分钟内走缓存）约可刷新 35 次/天；同一网络多人同时首次打开、或频繁硬刷新会打满额度，页面会如实显示「请求过于频繁（429），稍后自动重试」或「今日额度已用完」，退避后自动恢复，此时 ⑦ 只显示离线底图与气压带。
- **离线降级**：断网时 ⑤ 会显示明确错误并提供离线教学示例与手动输入兜底；⑦ 的底图、气压带与标注完全离线，等压线与实时标记显示获取失败提示，其余功能不受影响。

## ⚠️ 已知限制

- ⑦ 的三维地球瓦片是**运行时 canvas 自绘**的离线瓦片（Natural Earth 1:110m + 中国省界），层级仅 z0–z3（最细为 64 张），近看会偏模糊，也不能像在线地图那样无限放大。
- 极锋带、副热带高压带、赤道低压带为**气候示意**叠加，用来说明纬度带位置，不代表某一天的真实气压场；真实等压线是另一层（可单独开关），两者不要混读。
- 实时等压线受网格分辨率限制（15°≈1600 km）：等压线走向与疏密是量级正确的近似，小尺度低压/高压中心会被抹平；它适合「看大尺度气压场与风带」的课堂讨论，不能当官方天气图使用。
- ⑤⑦ 的实时天气与等压线均基于**数值模式**数据而非气象站实测；判读结论只用于课堂讨论，不构成天气预报。

## 🛠️ 开发与构建

```bash
# 开发：本地起静态服务即可
python3 -m http.server 8123

# 自检（零依赖，全部通过才正常）
node tools/selftest.mjs       # 页面/模块离线自检（116 项）
node tools/field-test.mjs     # 场数据单测：取数分块、缓存/429、等压线推导（192 项）

# 构建单文件离线版 → docs/index.html
node build.mjs

# 重新生成地图数据（一般不需要，raw 数据已入库）
node tools/build-geo.mjs
```
